## Prompt 1

This is for a university assignment (CS F301, Problem S1) in Racket 8.x.
Write (height tree) only.

A binary tree is either the empty list () or a three-element list
(value left right), where left and right are binary trees. Example:
(4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ())))

The height of () is 0. The height of a node is 1 plus the larger of the
heights of its two subtrees, so a single node has height 1. Use max.

## Prompt 2

height is correct. Write (leaf-count tree) only. It returns the number of
leaves. A leaf is a node whose left and right subtrees are both (). The empty
tree has no leaves. Do not change any existing function.

## Prompt 3

leaf-count is correct. Write (my-append a b) only. It returns a new list

## Prompt 4

Write (inorder tree) only. It returns the list of the tree's values in inorder
(left subtree, node, right subtree). The empty tree gives (). Subtrees are
always visited left first, then right. Use my-append, not append. The function
returns the list and prints nothing. Do not change any existing function.

## Prompt 5

Write (preorder tree) only. It returns the list of the tree's values in

existing function.

## Prompt 6

postorder (left subtree, right subtree, node). The empty tree gives (). Use

existing function.

## Prompt 7

Write (print-inorder tree) only. It prints the list of the tree's values in
inorder on one line using display, then prints a newline. Use the existing

## Prompt 8

Write (print-all-traversals tree) only. It prints three lines using display:
the inorder list, then the preorder list, then the postorder list. Each line
ends with a newline. Use the existing inorder, preorder and postorder
functions. The empty tree prints () on all three lines. Do not change any
existing function.

## Prompt 9

Write (print-height-and-leaves tree) only. It prints the two-element list
(height leaf-count) on one line using display, then prints a newline. Use the
existing height and leaf-count functions. The empty tree prints (0 0). Do not
change any existing function.

## Prompt 10
