## Prompt 1 (AI tool: Claude, Claude Code)

In G44_q2.pl, write split_list(List, Left, Right) that gives, on backtracking, every way to split List into two non-empty contiguous parts in order. Add a comment with its declarative reading.

## Prompt 2 (AI tool: Claude, Claude Code)

Write expr(Nums, Tree, Value) that gives, on backtracking, every expression tree over the non-empty list Nums (numbers used once, in order) using + - * /, and computes its integer Value while building it. Division is allowed only if the divisor is non-zero and the division is exact. Don’t build strings.

## Prompt 3 (AI tool: Claude, Claude Code)

Write tree_codes(Tree, Codes) that prints an expression tree in the canonical form from the assignment: * and / bind tighter than + and -, a left operand gets parentheses only if its precedence is lower than its parent’s, a right operand gets them if its precedence is the same or lower, and numbers never get them.

## Prompt 4 (AI tool: Claude, Claude Code)

Using split_list, expr and tree_codes, write equation(List, Equation) that gives valid equations as SWI-Prolog strings like “4*2=5+3”, and generate_equation(List, Equation) that gives one of them and fails cleanly for lists of length 0 or 1 or when none exist.

## Prompt 5 (AI tool: Claude, Claude Code)

Write all_equations(List, Equations) using findall and sort/2 (sorted, no duplicates, [] when there are none) and count_equations(List, N).
