## Prompt 1 (AI tool: Claude, claude.ai)

This is for a university assignment (CS F301, Problem P1) in SWI-Prolog.
Write solution/1 only.

There are four friends, always in the order 'Alex', 'Ben', 'Carla', 'Dana'.
A solution is a list of four terms p(Name, Dept, Lang, Project).

  Dept:    research, development, design, testing
  Lang:    python, java, 'c++', javascript
  Project: 'AI', web, embedded, data

Every value of every attribute is used exactly once, so each attribute is a
permutation of its four values (use permutation/2). Leave the clues out. This
predicate is only the candidate generator.
